# PCL Pocket Racing arcade overhaul

PCL Pocket Racing remains a browser-first multiplayer game set inside an oversized Perry-Castañeda Library. The overhaul keeps the existing Three.js world, WebRTC host authority, selectable cars, HUD, checkpoints, bots, time trials, and records. It adds an original colorful arcade-racing layer rather than copying any protected characters, names, tracks, or assets.

Driving gains three drift-charge tiers, stronger release boosts, improved visual feedback, and a dedicated item action. Item boxes award one of five original library-themed items: Study Sprint, Citation Shield, Book Stack, Ink Spill, or Library Cart. The authoritative host owns pickups, hazards, homing carts, impacts, and item use so every player sees the same result. The HUD shows the held item and drift tier.

The PCL scene gains luminous item boxes and renders active traps, carts, and shields. Existing library landmarks, oversized shelves, books, tables, signage, ramps, shortcuts, lighting, shadows, and toy-car models remain the environmental base. Presentation uses brighter race colors, clearer boost and item feedback, speed-responsive camera behavior, and the established Speedster HUD language.

Turtle Pond is removed from Manta, its Vercel project is deleted, and its GitHub repository is private and archived. Its local folder remains untouched.
